# 公開測試 Beta 驗證清單

本清單在 Beta／Open testing（公開測試）版本通過審查並發布後執行。實際版本、審查狀態、AAB 與 native debug symbols 雜湊以 `release-status.md` 為準，不在本檔永久寫入個別版本狀態。

## 首次啟動與權限流程

- [ ] 首次開啟 App 可正常顯示首頁。
- [ ] 點選通知存取設定前，App 有顯示醒目揭露。
- [ ] 使用者可選擇取消，不會被強迫授權。
- [ ] 使用者同意後會前往 Android 通知存取設定。
- [ ] 授權通知存取後，回到 App 可正常辨識權限狀態。
- [ ] 撤銷通知存取後，App 可正常回到未授權狀態，不閃退。

## 核心功能驗證

- [ ] 播放任一提供 MediaSession 的媒體 App 時，來源尚未被提升才建立媒體備援 Live Update。
- [ ] 同時播放本機與 Cast／遠端媒體時，只顯示系統優先順位最高的工作階段。
- [ ] 曲名、作者與專輯正確更新；有作者與專輯時內文顯示「作者 - 專輯」，且不顯示來源 App 名稱。
- [ ] 切歌、播放、暫停及時間跳轉只在來源支援時出現且可操作。
- [ ] 來源提供有效播放位置與時長時使用 ProgressStyle，App label、歌名與作者分列顯示且進度比例正確；資料不足時安全退回一般版型。
- [ ] Spotify podcast 顯示倒退 15 秒／暫停／快轉 15 秒；一般音樂未宣告時間跳轉能力時維持上一首／暫停／下一首。
- [ ] 來源只有 rewind／fast-forward、沒有精確 seek 能力時使用通用倒退／快轉文案，不錯誤承諾 15 秒。
- [ ] 暫停後媒體備援提醒保留 1 分鐘並改為「播放」action；期間恢復播放會取消清除，重複 metadata、通知或語言更新不會延長倒數。
- [ ] 暫停滿 1 分鐘、停止、播放錯誤、工作階段或來源通知消失後，媒體備援提醒會清除。
- [ ] 關閉工具分頁的媒體播放開關後不再建立備援提醒。
- [ ] 加入 Discord 伺服器語音頻道時建立 private、靜音的 Live Update，並鏡像來源連線標題與伺服器／頻道名稱；不顯示通話時長。
- [ ] Discord 的中斷、靜音／解除靜音與拒聽來源 action 依原始標題和順序顯示且可操作，點擊通知可回到目前通話。
- [ ] Discord 同一 notification key 更新時同步 Waiting、連線與靜音狀態；離開頻道或來源通知移除後立即清除，不受其他 Discord 通知移除影響。
- [ ] Discord 來源已由系統提升時不建立重複提醒；通知監聽器重連可恢復，關閉媒體分頁開關會立即清除並保留選擇。
- [ ] 普通 Discord 訊息、私人／群組通話與響鈴中的來電不會被宣稱或誤判為目前支援的伺服器語音頻道；Release build 不顯示 payload 查看入口。
- [ ] Discord 卡片在淺色、深色、大字級與橫向畫面維持藍紫品牌色及足夠對比，鎖定畫面不公開頻道名稱。
- [ ] Teams 已接通會議的 `CallsOngoing` 通知建立紫色、靜音的 Live Update，顯示對方名稱與不因來源更新而重置的通話時間。
- [ ] Teams 的「啟用通知」來源 action 顯示為「解除靜音」，「靜音」與「掛斷」維持原文且可操作；點擊通知可返回目前會議。
- [ ] Teams 來源通知移除、功能關閉或不再符合時立即清除；通知監聽器重連可恢復，一般訊息與響鈴中來電不會誤判。
- [ ] Teams 卡片在淺色、深色、大字級與橫向畫面使用獨立官方紫色並維持足夠對比；Release build 不顯示 payload 查看入口。
- [ ] Google 時鐘原生 Live Update 未生效時可建立備援提醒，且剩餘時間與來源一致。
- [ ] Android 17／Clock 9.0 原生 Live Update 生效時只顯示 Google 時鐘提醒，不產生第二則鏡像。
- [ ] 既有鏡像倒數後續轉為原生 Live Update 時，鏡像提醒會立即清除。
- [ ] 暫停、繼續與加一分鐘後可正確更新；倒數結束或來源通知移除後可清除。
- [ ] 同時存在多個計時器時只顯示來源指定的主要倒數。
