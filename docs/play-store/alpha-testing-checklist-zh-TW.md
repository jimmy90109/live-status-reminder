## 核心功能驗證

- [ ] Google 時鐘原生 Live Update 未生效時可建立備援提醒，且剩餘時間與來源一致。
- [ ] Android 17／Clock 9.0 原生 Live Update 生效時只顯示 Google 時鐘提醒，不產生第二則鏡像。
- [ ] 既有鏡像倒數後續轉為原生 Live Update 時，鏡像提醒會立即清除。
- [ ] 暫停、繼續與加一分鐘後可正確更新；倒數結束或來源通知移除後可清除。
- [ ] 同時存在多個計時器時只顯示來源指定的主要倒數。
- [ ] Google 時鐘碼表通知不會建立鏡像，也不會誤清除不同通知 key 的倒數提醒。
- [ ] Android 16 chronometer 與 Android 17 MetricStyle 路徑皆完成實機驗證。
- [ ] YouBike 2.0／2.0E 借車通知依車號顯示正確車種、騎乘時間、預估費用與下一次費用變更時間，相同車號還車後清除。
- [ ] YouBike 可自動辨識目前全臺服務區域；未知／同名站點可從通知 action 的可捲動 Dialog 選擇地區或其他地區，取消後仍維持未解析狀態。
- [ ] 桃園前 60 分鐘維持預估 NT$0，標題直接顯示 60 分鐘的下一個費用變更；新竹縣與竹科第一個 30 分鐘顯示預估 NT$10。
- [ ] 嘉義縣市、高雄、屏東的一般會員補助正確；嘉義縣市於 2027-01-01 自動恢復原價，跨年騎乘依借車時間判斷。
- [ ] 臺東 2.0 採 `12/24/48`、首 30 分鐘免費，2.0E 採 `25/50`、首 30 分鐘預估 NT$13；臺南市民卡、TPASS、特殊票卡與轉乘優惠不納入。
- [ ] 真正未知或手動選擇「其他地區」時不估價；關閉功能或超過 24 小時會清除 session。
- [ ] 深色／淺色模式、大字級與鎖定畫面下確認黃色卡片、Live Update 與地區 Dialog 可讀可操作。
- [ ] YouBike 卡片未授權時顯示準點更新說明；授權、拒絕、撤銷及重新授權後狀態正確，且不影響其他 App 功能。
